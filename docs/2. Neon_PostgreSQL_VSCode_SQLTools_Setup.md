# Connect Neon PostgreSQL to VS Code with SQLTools

## 1. Install the VS Code extensions

1. Open VS Code.
2. Press **Ctrl + Shift + X** to open Extensions.
3. Search for **SQLTools** (publisher: Matheus Teixeira) and install it.
4. Search for **SQLTools PostgreSQL/Cockroach Driver** and install it.
5. Open the **SQLTools** sidebar (database icon).

## 2. Get the Neon connection string

1. Open the Veridian project in the [Neon Console](https://console.neon.tech/).
2. Choose **Connect**, then select the `main` branch and `neondb` database.
3. Copy the connection string, or use the `DATABASE_URL` value in the local `.env` file.
4. Treat the URL as a secret. Do not paste it into source files or commit it.

## 3. Create a SQLTools connection

1. In SQLTools, choose **Add New Connection** and select **PostgreSQL**.
2. Choose **Connect using connection string** and paste the Neon URL locally.
3. Give the connection a descriptive name such as `Veridian Neon PostgreSQL`.
4. Keep TLS/SSL enabled. Store the connection in user settings rather than the project workspace so credentials are not committed.
